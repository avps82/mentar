# Year 1-12 English language & literature visual templates (2026-07-19)

Maintainer dump, LOGGED ONLY (same log-only pattern as every template round
logged earlier the same session — no action requested, no build). 10
templates across 4 sections, spanning Year 1 through senior secondary.

**Scope note, different from the science dump:** unlike
[[project_science_templates_idea]] (a domain with ZERO shipped curriculum
content), this project DOES already ship some English content (AU_ACARA/
IN_GENERIC breadth includes English alongside maths — see
[[project_r14a_au_breadth]]). So this is closer to the math template rounds
in character: some underlying content likely already exists at the basic
end (vocabulary, sentence structure), while the senior/analytical templates
(PEEL paragraphs, rhetorical triangle, comparative essay analysis) are
almost certainly well beyond anything shipped today. Needs a proper content
audit (what English nodes exist today, at what year levels) before assuming
any of this is a "just add a visual" job.

## Section 3: Analytical essay writing (secondary focus)

### Template 5 — the persuasive/analytical paragraph sandbox (PEEL model)

```text
  +--------------------------------------------------------------------------+

  | [ P ] POINT / TOPIC SENTENCE:   Introduce the main argument or idea.     |
  |     [                                                                  ] |
  | [ E ] EVIDENCE / EXAMPLE:       Provide a quote or fact that proves it.  |
  |     [                                                                  ] |
  | [ E ] EXPLANATION / ANALYSIS:   Unpack HOW the evidence supports the point.|
  |     [                                                                  ] |
  | [ L ] LINK / CONCLUDING LINE:   Tie the paragraph back to the big thesis. |
  +--------------------------------------------------------------------------+
```

### Template 6 — filled literature example (text: Shakespeare's *Macbeth*)

An exemplar breakdown analyzing unchecked ambition's corrosive, psychological
nature.

```text
  +--------------------------------------------------------------------------+

  | [ P ] POINT / TOPIC SENTENCE:                                            |
  |     Shakespeare utilizes the recurring motif of blood to demonstrate     |
  |     the inescapable psychological weight of guilt.                       |
  |                                                                          |
  | [ E ] EVIDENCE / EXAMPLE:                                                |
  |     Following the assassination of King Duncan, a fractured Macbeth      |
  |     bemoans, "Will all great Neptune's ocean wash this blood / Clean     |
  |     from my hand?"                                                       |
  |                                                                          |
  | [ E ] EXPLANATION / ANALYSIS:                                            |
  |     The hyperbole of cleansing an entire ocean underscores the sheer     |
  |     magnitude of his regret. By transforming literal physical stain      |
  |     into an un-washable spiritual blemish, the text signals that his     |
  |     moral transgression has permanently corrupted his psyche.            |
  |                                                                          |
  | [ L ] LINK / CONCLUDING LINE:                                            |
  |     Thus, the blood motif effectively anchors the overarching thesis     |
  |     that corrupt ambition ultimately triggers cognitive self-destruction.|
  +--------------------------------------------------------------------------+
```

**Licensing flag:** this filled example directly quotes *Macbeth* (public
domain, fine) but any FUTURE filled example using a copyrighted contemporary
text would need the same licence check as every other content source in this
project — see `docs/CONTENT_LICENSES.md` /
[[project_safeguarding_packet_and_us_licence]]. Not an issue for this
specific example, but worth remembering as a pattern before authoring more.

## What this would actually need if ever picked up

- **Content audit first:** what English curriculum nodes already exist
  (year levels, topics), before assuming any of this is "just needs a
  visual." Sections 1-2 (vocabulary, sentence structure, story mountain)
  are plausibly close to existing early-years content; Sections 3-4 (PEEL
  paragraphs, rhetorical triangle, comparative literature analysis) are
  senior-secondary essay-writing skills, almost certainly beyond anything
  shipped today.
- **Verification posture is qualitative, not computed** — same open
  question as [[project_science_templates_idea]]: there's no
  `eval/verify_numeric.check`-style deterministic ground truth for "is this
  PEEL paragraph analysis correct," a fundamentally different problem from
  arithmetic's "computed ground truth, LLM never decides correctness"
  posture. Needs its own design thinking, not a direct reuse of
  `arithmetic_steps.py`'s approach.
- **Text licensing** — any future filled/worked example quoting a text
  needs the same check as every other content source (see Template 6's
  note above).
