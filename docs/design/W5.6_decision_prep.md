# W5.6 — Two open kill-criteria decisions

`SPEC §25.1` pre-commits kill criteria (a)–(d); two are still open. This doc tees them up so
you can sign off without starting from scratch. **It does not make the calls** — it presents the
options + a recommendation. Decisions go back into SPEC §25.1; this doc then links from there.

---

## (c) — "Pilot learner shows genuine distress or withdraws assent"

**Current state (SPEC §25.1c):** deferred to Bucket D. No auto-stop *mechanism* exists; the
**present parent's judgment governs** (parent-mediated pilot); per-input distress is handled by
SAFETY Layer 3. Must **not** halt on normal frustration ("I hate fractions" ≠ distress).

**The real constraint:** a numeric auto-stop (e.g. "N distress triggers → halt") is premature —
there's no distress-signal mechanism yet, and a too-eager rule erodes trust by halting on ordinary
struggle. So the decision is *which interim policy to ratify*, not a threshold number.

| Option | What it means | Trade-off |
|---|---|---|
| **A — Ratify continuous-assent (recommended)** | Keep parent-as-judge; **document the standard explicitly**: continuous assent (child agrees *and* can stop anytime), anchored on UNICEF ERIC + standard IRB child-assent + NSPCC. Add a one-line "you can stop anytime" to the child at session start, and treat a parent-ended session as a recorded loss-of-assent signal (already wired: `/parent/ack` end + `escalation_log`). **No numeric auto-stop.** | Lowest false-halt risk; honest about the missing mechanism; gives a clear standard to revisit against. Relies on the present parent (acceptable for the supervised single-family pilot only). |
| B — Define a numeric auto-stop now | e.g. halt after K consecutive distress-class triggers | **Not recommended** — no mechanism exists; halts on normal frustration; the maintainer already deferred this. |

**What you decide:** confirm **Option A** (or amend). If A: OK to add the session-start
"you can stop anytime" line + record parent-end as loss-of-assent? (Both are small, locally-doable.)

> ⚠️ The assent standard cites UNICEF ERIC / IRB / NSPCC — **verify against those sources** before
> it's treated as authoritative (Bucket D).
