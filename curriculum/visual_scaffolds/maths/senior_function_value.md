When writing or explaining this question, use this visual structure:

```key
f(x) = x² + 3x + 1     f(2) means: put 2 wherever x appears
f(2) = 2² + 3×2 + 1 = 4 + 6 + 1 = 11
```

**Guidelines for the question text:**
- Show the substitution line before any arithmetic — every x replaced at once.
