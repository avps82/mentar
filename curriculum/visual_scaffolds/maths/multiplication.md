When writing or explaining this question, use ONE of these visual structures:

**Equal groups** — circles or boxes each holding the same count:
```
(●●●)  (●●●)  (●●●)  (●●●)
  4 groups of 3 = 12
```

**Array** — rows × columns grid:
```
● ● ● ●
● ● ● ●
● ● ● ●
3 rows × 4 columns = 12
```

**Area model (for 2-digit × 1-digit)**:
```
      30      +     4
   +--------+------+
4  |  120   |  16  |  = 136
   +--------+------+
```

**Guidelines for the question text:**
- Year 2–3: equal groups or array, factors ≤ 10.
- Year 4–5: area model for 2-digit × 1-digit; introduce partial products.
- For fraction × whole (Year 5+): use the bar model from the fractions scaffold.
- Describe the model in words in the child-facing question ("imagine 4 rows of 3 dots").
