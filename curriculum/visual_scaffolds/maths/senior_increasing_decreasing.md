When writing or explaining this question, use this visual structure:

```key
dy/dx > 0 → increasing ↗      dy/dx < 0 → decreasing ↘
dy/dx = 0 → stationary →
```

**Guidelines for the question text:**
- Compute the derivative's VALUE at the point; only its sign matters.
