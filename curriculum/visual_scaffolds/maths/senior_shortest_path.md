When writing or explaining this question, use this visual structure:

```key
shortest path = the route whose edge weights ADD to the least
A ──3── B ──4── C   total 7
A ────6──── C       total 6  ← shorter, though it uses fewer edges
```

**Guidelines for the question text:**
- List each candidate route with its total; fewest edges is NOT the rule, least total is.
