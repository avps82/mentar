When writing or explaining this question, use this visual structure:

```key
up-slope cloud  ↗  positive correlation
down-slope cloud ↘ negative correlation
no slope / round cloud → no correlation
```

**Guidelines for the question text:**
- Direction is about the TREND of the cloud, not about any single point.
