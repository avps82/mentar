When writing or explaining this question, use this visual structure:

```key
unit price = total price ÷ number of items
Pack A: $12 for 4 → $3 each   Pack B: $10 for 2 → $5 each → A wins
```

**Guidelines for the question text:**
- Compare per-ONE-item prices only; never compare pack prices directly.
