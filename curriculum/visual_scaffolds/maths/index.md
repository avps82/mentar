# Maths Visual Scaffolds

Visual scaffold hints for mathematics topics.

* [addition_subtraction](addition_subtraction.md) — Visual scaffold hints for whole-number addition and subtraction
* [algebra_equations](algebra_equations.md) — Visual scaffold hints for solving linear equations using balance and inverse operations
* [algebraic_area_perimeter](algebraic_area_perimeter.md) — Visual scaffold hints for writing perimeter or area from a shape with algebraic sides
* [algebraic_expressions](algebraic_expressions.md) — Visual scaffold hints for translating a worded description into an expression
* [area_perimeter](area_perimeter.md) — Visual scaffold hints for area and perimeter of rectangles (and other 2D shapes)
* [combining_expressions](combining_expressions.md) — Visual scaffold hints for adding or subtracting expressions by matching like terms
* [decimals](decimals.md) — Visual scaffold hints for decimal place value, addition, and subtraction
* [division_word_problems](division_word_problems.md) — Visual scaffold hints for division, sharing, and grouping word problems
* [fractions](fractions.md) — Visual scaffold hints for fraction concepts including unit fractions, equivalent fractions, and comparing fractions
* [multiplication](multiplication.md) — Visual scaffold hints for multiplication including arrays, area models, and times tables
* [negative_numbers](negative_numbers.md) — Visual scaffold hints for negative numbers in context (temperature, depth, above/below zero)
* [number_patterns](number_patterns.md) — Visual scaffold hints for number sequences, skip counting, and doubling/halving
* [order_of_operations](order_of_operations.md) — Visual scaffold hints for order of operations (brackets, indices, division/multiplication, addition/subtraction)
* [percentages](percentages.md) — Visual scaffold hints for percentage concepts including converting between fractions, decimals, and percentages
* [place_value](place_value.md) — Visual scaffold hints for whole-number place value — what each digit in a number is worth
* [probability](probability.md) — Visual scaffold hints for probability concepts including likelihood scale and sample spaces
* [squares_roots](squares_roots.md) — Visual scaffold hints for squaring numbers and square roots using area models
