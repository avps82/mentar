When writing or explaining this question, use this visual structure:

```key
(a + bi) + (c + di) = (a + c) + (b + d)i
real with real, imaginary with imaginary:
(3 + 2i) + (1 + 5i) = 4 + 7i
```

**Guidelines for the question text:**
- Underline real parts and imaginary parts in different styles before adding.
