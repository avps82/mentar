When writing or explaining this question, use ONE of these visual structures (choose the one that best fits the specific question):

**Bar model** — a horizontal rectangle divided into equal parts, shaded parts shown:
```
|████|████|    |    |
  1/2 shaded        2/4 shaded
```
Label each part with its fraction value. Shade the relevant portion.

**Number line 0–1** — evenly spaced tick marks, fraction labelled above the line:
```
0----1/4----1/2----3/4----1
         ↑
       here
```

**Guidelines for the question text:**
- State the denominator visually (e.g. "a bar cut into 4 equal parts").
- For comparing, show BOTH fractions side by side on the same scale.
- For equivalent fractions, show two different-looking bars with the same shaded amount.
- Keep numbers small: denominators 2, 3, 4, 6, 8 only for Year 2–5; up to 12 for Year 6+.
- Do not draw diagrams as raw ASCII in the child-facing question — describe them in plain words ("a bar split into 4 equal pieces, 3 shaded").
