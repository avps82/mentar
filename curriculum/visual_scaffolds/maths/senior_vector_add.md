When writing or explaining this question, use this visual structure:

```key
(a₁, a₂) + (b₁, b₂) = (a₁ + b₁, a₂ + b₂)
(2, 1) + (3, 4) = (5, 5)   — x with x, y with y, never across
```

**Guidelines for the question text:**
- Stack the two vectors and add straight down each column.
