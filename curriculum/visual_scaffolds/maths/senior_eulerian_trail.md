When writing or explaining this question, use this visual structure:

```key
count vertices with an ODD number of edges:
0 odd → Eulerian circuit (start = end)
2 odd → Eulerian trail (start and end at the odd pair)
more than 2 odd → impossible
```

**Guidelines for the question text:**
- Label each vertex with its degree before deciding; the rule reads off the odd count.
