When writing or explaining this question, use ONE of these visual structures:

**Probability scale** — horizontal line 0 to 1 with labelled landmarks:
```
0         1/4        1/2        3/4         1
|----------|----------|----------|----------|
impossible  unlikely    even     likely    certain
```
Place the event's probability as a point on this scale.

**Tree diagram** — branches for each stage of an experiment:
```
         H (1/2)
First /
toss  \
         T (1/2)
```
Extend branches for multi-stage experiments.

**Fraction / ratio notation**:
- Express probability as a fraction: P(heads) = 1/2.
- For Year 6+: also express as decimal (0.5) and percentage (50%).

**Guidelines for the question text:**
- Year 5–6: probability scale and simple fractions only.
- Year 7+: tree diagrams and multi-stage experiments.
- Always define the sample space in the question ("a bag has 3 red and 2 blue marbles").
- Describe the scale or tree in words in the child-facing question.
