When writing or explaining this question, use this visual structure:

```key
for y = x² + bx + c the vertex sits at x = −b ÷ 2
   \        /
    \      /
     \____/   ← vertex: the lowest (or highest) point
```

**Guidelines for the question text:**
- The vertex x-value comes from the formula; the y-value by substituting back.
