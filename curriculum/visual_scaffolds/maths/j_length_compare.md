When writing or explaining this question, use this visual structure:

```key
▬▬▬▬▬▬▬▬▬▬▬▬  the longer one
▬▬▬▬▬▬        the shorter one
      ^^^^^^  the bit sticking out past the shorter one
              = how much longer
```

**Guidelines for the question text:**
- Draw the two things one above the other, LINED UP at the same left edge --
  the difference is only visible when they start together.
- Deliberately NO object names here. This scaffold is appended under an item's
  own worked example, and that example names its own two objects: a version
  saying "pencil (shorter)" sat directly beneath a card reading "the pencil is
  9 cm longer" (2026-08-22). A generic picture cannot contradict the item.
- Draw the bars in PROPORTION, not to scale. Scaled cells invite a child to
  count the gap instead of subtracting, and the node is testing the subtraction
  -- see engine/visuals.py:length_bars.
- Weight comparison belongs to `year1_comparing.md`, not here: a set of scales
  under a "how much longer" question is answering a question nobody asked.
