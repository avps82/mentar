When writing or explaining this question, use this visual structure:

```key
a · b = a₁b₁ + a₂b₂ + a₃b₃
(1, 2, 3) · (4, 5, 6):
  1×4   2×5   3×6
   4  +  10 +  18  = 32
```

**Guidelines for the question text:**
- Line the vectors up vertically and multiply straight down each column, then add.
