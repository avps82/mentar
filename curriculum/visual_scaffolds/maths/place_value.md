When writing or explaining this question, use ONE of these visual structures:

**Place-value column table**:
```
Hundreds | Tens | Ones
    3    |  5   |  2
  (300)  | (50) | (2)
```

**Expanded form**:
```
  352 =  300 +  50 + 2
4,707 = 4000 + 700 + 0 + 7   (the 0 place is shown, worth nothing)
```

**Guidelines for the question text:**
- Keep numbers to 4 digits or fewer.
- Ask about ONE digit's value at a time.
- The digit's POSITION gives its value (e.g., "the 4 in 47 is worth 40, not 4").
- This scaffold is for WHOLE numbers only; decimal place value (tenths, hundredths) has
  its own scaffold.
