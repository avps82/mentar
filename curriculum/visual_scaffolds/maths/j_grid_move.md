When writing or explaining this question, use this visual structure:

```key
(across, up)      right +1 across      left -1 across
                  up    +1 up          down -1 up
(3, 2) move 3 right -> (3+3, 2) = (6, 2)   across = 6
```

**Guidelines for the question text:**
- A move changes ONE of the two numbers; the other stays exactly as it was.
- Say which number the answer wants -- the across number or the up number.
