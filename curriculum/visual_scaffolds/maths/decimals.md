When writing or explaining this question, use ONE of these visual structures:

**Place-value chart** — columns for ones, tenths, hundredths:
```
| Ones | . | Tenths | Hundredths |
|  3   | . |   4    |     2      |
       = 3.42
```
Highlight the target digit's column when asking about place value.

**Number line** — labelled at whole numbers, tick marks at tenths:
```
3.0  3.1  3.2  3.3  3.4  3.5
 |----|----|----|----|----|-→
              ↑
```

**Column addition/subtraction** — digits aligned on the decimal point:
```
  3.40
+ 2.60
------
  6.00
```

**Guidelines for the question text:**
- For "what does the digit X represent" questions, name the column in the question ("in 3.42, what does the 4 represent?").
- For addition/subtraction, always align decimal points. Show carrying/borrowing if within the question's scope.
- For Year 5: tenths and hundredths only. Year 6+: thousandths allowed.
- Diagrams go in a fenced block (see the examples above) — not emoji shapes. In a written
  question, describe the chart in plain words instead of drawing it.
