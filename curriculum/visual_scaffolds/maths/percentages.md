When writing or explaining this question, use ONE of these visual structures:

**Hundred grid** — a 10×10 grid where each cell = 1%; shade the relevant portion:
```
██████████  ← 10 shaded cells
██████████    in the first row
□□□□□□□□□□    = 20 out of 100
□□□□□□□□□□    = 20%
□□□□□□□□□□
□□□□□□□□□□
□□□□□□□□□□
□□□□□□□□□□
□□□□□□□□□□
□□□□□□□□□□
```

**Fraction–decimal–percent triple** — three ways to write the same value:
```
  1/4   =   0.25   =   25%
  1/2   =   0.50   =   50%
  3/4   =   0.75   =   75%
```

**Number line 0%–100%**:
```
0%      25%      50%      75%     100%
|--------|--------|--------|--------|
                  ↑
```

**Guidelines for the question text:**
- Always anchor percentages to "out of 100" language first.
- For fraction↔percent conversion: use the triple notation above.
- Year 5–6: 10%, 25%, 50%, 75% and their fraction/decimal equivalents.
- Year 7+: all multiples of 5%, then any integer percent, then non-integer.
- Describe the grid or line in words; do not use raw ASCII in the child-facing question.
