When writing or explaining this question, use this visual structure:

```key
            col 1  col 2  col 3
row 1     [  4      7      2  ]
row 2     [  5      1      8  ]     entry (2, 3) = 8
row FIRST (top-down), then column (left-right)
```

**Guidelines for the question text:**
- Trace the row with one finger and the column with another — the entry is where they meet.
