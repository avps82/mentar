When writing or explaining this question, use ONE of these visual structures:

**Square grid (area model)** — n² is the area of an n×n square:
```
4² = 4 × 4 = 16

□□□□
□□□□
□□□□
□□□□   ← 4 rows, 4 columns = 16 unit squares
```

**Square root as side length** — √16 = 4 because a 4×4 square has area 16:
```
Area = 16
  +----+
  |    |  ← side = √16 = 4
  |    |
  +----+
```

**Perfect squares reference table**:
```
1²=1  2²=4  3²=9  4²=16  5²=25
6²=36  7²=49  8²=64  9²=81  10²=100
```

**Guidelines for the question text:**
- Introduce squaring as "multiply the number by itself" before using index notation.
- Year 8: include both squaring AND finding square roots of perfect squares.
- For non-perfect squares: "between which two integers does √30 lie?" (between 5 and 6).
- Write x² as "x squared" in child-facing text alongside the symbol.
