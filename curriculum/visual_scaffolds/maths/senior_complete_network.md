When writing or explaining this question, use this visual structure:

```key
complete network on n vertices: edges = n × (n − 1) ÷ 2
4 vertices → 4×3÷2 = 6 edges (a square plus both diagonals)
```

**Guidelines for the question text:**
- Each pair of vertices contributes exactly one edge — count pairs, not lines drawn.
