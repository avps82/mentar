When writing or explaining this question, use this visual structure:

```key
relative frequency = number of times it happened ÷ number of trials
12 heads in 48 tosses → 12/48 = 1/4 = 0.25
```

**Guidelines for the question text:**
- Always name both counts before dividing; simplify the fraction at the end.
