When writing or explaining this question, use this visual structure:

```key
scale 1 : n  →  real length = drawing length × n
drawing 2 cm at 1:100  →  real 200 cm = 2 m
```

**Guidelines for the question text:**
- State the scale as 1 : n and keep units visible at every step.
