When writing or explaining this question, use this visual structure:

```key
magnitude of (x, y, z) = √(x² + y² + z²)
(1, 2, 2) → √(1 + 4 + 4) = √9 = 3
```

**Guidelines for the question text:**
- Same idea as 2D with a third square added — show all three squares separately.
