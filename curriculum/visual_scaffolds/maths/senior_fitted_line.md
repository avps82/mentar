When writing or explaining this question, use this visual structure:

```key
fitted rule: y = a + b×x
x = 6, rule y = 20 + 3x → y = 20 + 18 = 38
on the plot: go UP from x to the line, then ACROSS to read y
```

**Guidelines for the question text:**
- Say whether the x-value sits inside the data range — outside it the prediction weakens.
