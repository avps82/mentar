When writing or explaining this question, use this visual structure:

```key
∫ 2x dx from 0 to k:  antiderivative x², evaluate ends, subtract
k² − 0² = k²
```

**Guidelines for the question text:**
- Name the antiderivative first, then substitute both ends — never merge the steps.
