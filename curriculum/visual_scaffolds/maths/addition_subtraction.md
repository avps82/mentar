When writing or explaining this question, use ONE of these visual structures:

**Number line (jump strategy)** — start at one number, hop forward (add) or back (subtract):
```
+6
←——→
12   18
|----+----+----+----+----+-→
```

**Column layout** — digits stacked, ones on the right:
```
  47
+ 35
----
  82   (carry the 1)
```

**Number bonds / part-part-whole**:
```
      82
     /  \
   47    35
```

**Guidelines for the question text:**
- For Year 2–3: use number lines; totals ≤ 100.
- For Year 4+: column layout; totals up to 10 000.
- When carrying or borrowing is involved, call it out explicitly in the explanation.
- Describe the jump or column visually in words, not raw ASCII, in the child-facing question.
