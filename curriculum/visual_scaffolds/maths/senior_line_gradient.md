When writing or explaining this question, use this visual structure:

```key
gradient = rise ÷ run = (y₂ − y₁) ÷ (x₂ − x₁)
        ● (x₂, y₂)
  rise │
  ●────┘ (x₁, y₁)
   run
```

**Guidelines for the question text:**
- Label which point is (x₁, y₁) first; subtract in the same order top and bottom.
