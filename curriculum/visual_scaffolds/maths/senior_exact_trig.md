When writing or explaining this question, use this visual structure:

```key
angle   0°    30°    45°    60°    90°
sin     0    1/2   √2/2   √3/2    1
cos     1   √3/2   √2/2    1/2    0     tan 45° = 1
```

**Guidelines for the question text:**
- Read straight from the table — these values are exact, never decimals.
