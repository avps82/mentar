When writing or explaining this question, use this visual structure:

```key
C = 40 + 25n   (call-out fee + rate × hours)
n = 3:  25 × 3 = 75  →  C = 40 + 75 = 115
multiply BEFORE adding — the fee is added once, the rate every hour
```

**Guidelines for the question text:**
- Name what each letter stands for before substituting anything.
