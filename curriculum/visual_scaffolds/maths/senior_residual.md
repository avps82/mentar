When writing or explaining this question, use this visual structure:

```key
residual = actual y − predicted y
point above the line → positive residual; below → negative
     ● actual
     │ residual
  ───┴─── line (predicted)
```

**Guidelines for the question text:**
- Draw the residual as a short vertical stick between the point and the line.
