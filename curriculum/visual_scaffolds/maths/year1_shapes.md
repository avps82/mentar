When writing or explaining this question, use this visual structure:

```key
△ triangle: 3 sides    □ square: 4 sides
⬠ pentagon: 5          ⬡ hexagon: 6
trace the edge — count each straight side once
```

**Guidelines for the question text:**
- Number each side as it is counted (1, 2, 3…).
