When writing or explaining this question, use this visual structure:

```key
argument = anticlockwise angle from the positive real axis
        i (90°)
        │   ↗ 1+i (45°)
−1 ─────┼───── 1 (0°)
(180°)  │
```

**Guidelines for the question text:**
- Plot the number FIRST; the angle is read from the picture, not computed blind.
