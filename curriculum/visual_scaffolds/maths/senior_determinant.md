When writing or explaining this question, use this visual structure:

```key
| a  b |
| c  d |   det = a×d − b×c   (main diagonal minus other diagonal)
```

**Guidelines for the question text:**
- Draw the two diagonals as crossing arrows: ↘ product minus ↗ product.
