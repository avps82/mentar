When writing or explaining this question, use this visual structure. There is NO
equation to solve here and NO "=" balance — the task is building or combining an
expression, not isolating a variable (that is algebra_equations.md).

**Word-to-expression table** — map each phrase piece to a symbol:
```key
"3 more than"     ->   + 3
"twice a number"  ->   2 × (number)
"a number n"      ->   n
------------------------------------
"3 more than twice a number n"  ->  2n + 3
```

**Guidelines for the question text:**
- The answer IS an expression (e.g. "4x + 8"), never a number and never an equation
  with "=" in it — the child types just the expression.
- Never ask the child to "expand"/"factorise"/"simplify" a SINGLE expression already
  shown in the question — any equivalent form (expanded or not) scores as correct, so
  that phrasing can't tell whether the child did anything. Only ask questions where the
  answer must be built from a word description or from combining separate pieces.
