When writing or explaining this question, use this visual structure:

```key
angle at the centre = 2 × angle at the circumference (same arc)
     ⌒ arc
    /  \      circumference angle θ
   ●────●     centre angle 2θ
```

**Guidelines for the question text:**
- Mark the shared arc first — the theorem only holds for angles on the same arc.
