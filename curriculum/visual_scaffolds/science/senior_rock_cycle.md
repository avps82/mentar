When writing or explaining this question, use this visual structure:

```key
magma ──cool──► IGNEOUS (basalt, granite)
  ▲                │ weather + deposit
  melt        SEDIMENTARY (sandstone, limestone) — layers, fossils
  │                │ heat + pressure
  └──── METAMORPHIC (marble, slate)
```

**Guidelines for the question text:**
- Arrows are processes — name the process on every arrow you mention.
