When writing or explaining this question, use this visual structure:

```key
galvanic: reaction WANTS to run → makes current   (battery)
electrolytic: current FORCES reaction backwards   (electroplating)
both:  AN-OX (anode = oxidation)   RED-CAT (cathode = reduction)
```

**Guidelines for the question text:**
- Draw the electron arrow through the wire, never through the solution.
