When writing or explaining this question, use ONE of these visual structures:

**Transparent vs. opaque** — side-by-side comparison:
```
TRANSPARENT (light passes through clearly)   OPAQUE (blocks light completely)
  clear glass, clean water                     a brick wall, a wooden door
  clear plastic wrap                            a metal spoon, a thick book
  (you can see clearly through it)              (no light gets through — it
                                                   makes a solid shadow)
```

**Light path diagram**:
```
LIGHT SOURCE  →  [transparent material]  →  light continues through, object seen clearly
LIGHT SOURCE  →  [opaque material]       →  light STOPS, a dark shadow forms behind it
```

**Guidelines for the question text:**
- Give ONE material and ask whether it is transparent or opaque.
- Stick to the two-way transparent/opaque split for this node — translucent (partly lets
  light through, like frosted glass) is a 3rd category, don't mix it in unless the node
  explicitly covers it.
