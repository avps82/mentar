When writing or explaining this question, use this visual structure:

```key
wood:  pencil, door        (from trees, feels warm)
metal: saucepan, key       (hard, shiny, cold)
glass: window, clear cup   (smooth, see-through)
```

**Guidelines for the question text:**
- Name the material's FEEL — that is how a six-year-old tests it.
