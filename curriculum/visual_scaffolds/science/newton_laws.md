When explaining this question, use ONE of these visual structures:

**The three laws, one line each**:
```
FIRST   no resultant force  ->  no CHANGE in motion       (inertia)
        a puck sliding on frictionless ice at steady speed

SECOND  resultant force     ->  acceleration = F / m
        the same push accelerates a light trolley more than a heavy one

THIRD   forces come in PAIRS, on two different objects
        a rocket pushes gas down, the gas pushes the rocket up
```

**Which law is this?**
```
Nothing changing?          -> FIRST
Something accelerating?    -> SECOND
Two objects pushing back?  -> THIRD
```

**Guidelines for the question text:**
- Give a situation and ask which law explains it.
- Third-law pairs act on DIFFERENT objects -- that is what separates them from balanced forces.
