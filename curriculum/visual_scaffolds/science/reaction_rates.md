When explaining this question, use ONE of these visual structures:

**Four ways to change the rate — all through collisions**:
```
CHANGE                       EFFECT     WHY
raise the temperature        faster     particles move faster: more collisions,
                                        and more of them energetic enough
increase the concentration   faster     more particles in the same space
powder instead of a lump     faster     more surface exposed to react
add a catalyst               faster     a lower-energy route to the same product
```

**Collision theory in one line**:
```
a reaction happens only when particles COLLIDE with enough ENERGY.
anything that raises the number or the energy of collisions raises the rate.
```

**Slowing it down is the same lever, reversed**:
```
cool it · dilute it · use one big lump · remove the catalyst
```

**Guidelines for the question text:**
- Give a change and ask whether it speeds the reaction up or slows it down.
- A catalyst is not used up, and it never changes how much product you finally get.
