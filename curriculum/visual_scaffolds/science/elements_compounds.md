When writing or explaining this question, use ONE of these visual structures:

**Element vs. compound** — side-by-side comparison:
```key
ELEMENT (only one type of atom)   COMPOUND (two+ elements chemically joined)
  oxygen, iron, gold, carbon        water (H2O), carbon dioxide (CO2)
  (cannot be broken down into       table salt (NaCl), sugar (glucose)
   simpler substances)              (the letters in the formula show
                                      which elements are joined)
```

**Formula reading**:
```
H2O  →  H (hydrogen) + O (oxygen), joined  →  a COMPOUND (2 different elements)
O2   →  O (oxygen) + O (oxygen), same one  →  an ELEMENT (only oxygen atoms)
```

**Guidelines for the question text:**
- Give ONE substance and ask whether it is an element or a compound.
- Both elements and compounds are pure substances (see `mixtures.md`) — the difference is
  whether the pure substance is made of one type of atom (element) or two-plus types
  chemically bonded together (compound). A mixture is neither: its parts are just mixed,
  not chemically joined.
