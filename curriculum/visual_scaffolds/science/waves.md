When explaining this question, use ONE of these visual structures:

**The two wave types, side by side**:
```
TRANSVERSE  — the shaking is ACROSS the direction of travel
      ／‾＼      ／‾＼          travel ──────>
     ／    ＼  ／    ＼         shake  ↕
   ＼＿／      ＼＿／
   (light, water ripples, a shaken rope)

LONGITUDINAL — the shaking is ALONG the direction of travel
   ||| |  |  ||| |  |  |||     travel ──────>
   ^compressed  ^spread out    shake  ↔
   (sound in air, a pushed spring, ultrasound, seismic P-waves)
```

**One-question test**:
```
Ask: which way do the particles move compared with the wave?
  at right angles to it  -> TRANSVERSE
  back and forth along it -> LONGITUDINAL
```

**Guidelines for the question text:**
- Give a real example and ask which type it is; do not ask for a definition to be recited.
- Sound in air is the anchor example for longitudinal; light is the anchor for transverse.
