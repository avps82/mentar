When writing or explaining this question, use ONE of these visual structures:

**Flexible vs. rigid** — side-by-side comparison:
```
CAN BE BENT, TWISTED, STRETCHED     STAYS THE SAME SHAPE (until it BREAKS)
  a rubber band                       a glass cup
  a pipe cleaner                      a wooden ruler
  playdough                           a ceramic plate
  a piece of string                   a china bowl
```

**Same material, new shape** — the key idea:
```
BEFORE: a straight pipe cleaner  →  ACTION: bend it  →  AFTER: a curved pipe cleaner
        (still the SAME material — still metal and fuzz, just a different shape)
```

**Guidelines for the question text:**
- Multiple-choice only (verifier uses curated fact tables, never LLM assertion).
- The key idea: bending/twisting/stretching changes an object's SHAPE, not what it's
  MADE OF — a bent paperclip is still metal.
- Rigid materials (glass, ceramic, wood) don't bend or stretch — force enough and they
  BREAK into pieces instead, but each piece is still the same material.
- Don't ask the child to distinguish bending vs. twisting vs. stretching from each
  other (genuinely ambiguous even for an adult) — only "can this be reshaped this way
  at all" vs. "no, it stays rigid".
