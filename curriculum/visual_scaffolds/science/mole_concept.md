When explaining this question, use ONE of these visual structures:

**Three different questions about the same sample**:
```key
HOW MANY particles?    amount of substance   moles      (6.02 x 10^23 per mole)
HOW HEAVY?             mass                  grams
HOW CONCENTRATED?      concentration         mol/L
```

**The mole is a counting word**:
```
a dozen eggs   = 12 eggs
a mole of atoms = 6.02 x 10^23 atoms

mass (g) = moles x molar mass (g/mol)
```

**Guidelines for the question text:**
- Ask which quantity a unit or phrase measures; mass and amount are the classic confusion.
- Never ask for the Avogadro constant to be recalled to more than 3 significant figures.
