When explaining this question, use ONE of these visual structures:

**One loop, or several branches**:
```
SERIES                              PARALLEL
  +--(X)--(X)--+                      +--(X)--+
  |            |                      |       |
  +----| |-----+                      +--(X)--+
                                      |       |
  one path for the current            +--| |--+
                                      each branch is its own path
```

**What each arrangement does**:
```
                      SERIES                    PARALLEL
current               same through every part   splits between branches
voltage               shared between parts      full supply across each branch
one component fails   everything goes out       the others stay on
```

**Why house lighting is parallel**:
```
one blown bulb must not darken the whole house  -> parallel
fairy lights wired in one loop                  -> series (one fails, all fail)
```

**Guidelines for the question text:**
- State a behaviour and ask which arrangement it describes.
- The "one lamp fails" test is the fastest way for a child to tell them apart.
