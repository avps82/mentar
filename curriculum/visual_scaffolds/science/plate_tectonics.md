When explaining this question, use ONE of these visual structures:

**The three boundary types**:
```
MOVING APART            <──  │  ──>      new crust fills the gap
                             │            -> mid-ocean ridge, rift valley

MOVING TOGETHER         ──>  │  <──      one plate is pushed down or crust crumples
                             │            -> ocean trench, fold mountains, island arc

SLIDING PAST            ──>  │           plates grind sideways, no new crust
                        <──  │            -> transform fault
```

**Landform → boundary lookup**:
```
mid-ocean ridge      apart
rift valley          apart
deep ocean trench    together
fold mountains       together
volcanic island arc  together
transform fault      sliding past
```

**Guidelines for the question text:**
- Name a landform and ask which movement made it (or the reverse).
- Earthquakes happen at all three; only the LANDFORM distinguishes them.
