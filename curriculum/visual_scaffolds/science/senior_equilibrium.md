When writing or explaining this question, use this visual structure:

```key
A + B  ⇌  C + D
at equilibrium: forward rate = reverse rate (both still running)
push the system (add, heat, squeeze) → it shifts to UNDO the push
```

**Guidelines for the question text:**
- Say 'dynamic' out loud: amounts constant because both directions balance.
