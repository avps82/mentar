When writing or explaining this question, use this visual structure:

```key
REDUCE   — insulate homes, share transport (best: never use it)
REUSE / RECYCLE — refill, compost, keep materials in the loop
RESTORE  — replant riverbanks, return wetlands
```

**Guidelines for the question text:**
- Order matters: reducing beats recycling beats restoring after damage.
