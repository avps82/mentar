When explaining this question, use ONE of these visual structures:

**Same number, different meaning**:
```
SCALAR   size only                 "60 km/h"
VECTOR   size AND direction        "60 km/h due north"

speed  <- scalar        velocity      <- vector
mass   <- scalar        force         <- vector
energy <- scalar        acceleration  <- vector
distance <- scalar      displacement  <- vector
```

**The walk test**:
```
Walk 3 km east, then 3 km west.
  DISTANCE travelled  = 6 km   (scalar -- just how far you walked)
  DISPLACEMENT        = 0 km   (vector -- you are back where you started)
```

**Guidelines for the question text:**
- Name a quantity and ask which kind it is; the paired scalar/vector words are the trap.
- A vector quoted without its direction is an incomplete answer.
