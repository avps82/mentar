When explaining this question, use ONE of these visual structures:

**What an enzyme IS**:
```
a PROTEIN catalyst
  · lowers the activation energy
  · specific -- its active site fits ONE substrate shape
  · not used up, so one enzyme works over and over
```

**Lock and key**:
```
   substrate        active site
      /\     +     \    /      ->   enzyme-substrate complex  ->  products
     /  \           \__/                                          + unchanged enzyme
```

**What changes the rate**:
```
temperature up to the optimum   faster
past the optimum                DENATURED -- the active site loses its shape
wrong pH                        denatured for the same reason
```

**Guidelines for the question text:**
- Ask what is true of enzymes, with carbohydrate/used-up/any-pH as the distractors.
- "Denatured" means the SHAPE is lost, not that the enzyme was consumed.
