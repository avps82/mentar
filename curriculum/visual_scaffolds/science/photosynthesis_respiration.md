When explaining this question, use ONE of these visual structures:

**Two reactions that run opposite ways**:
```
PHOTOSYNTHESIS   carbon dioxide + water --light--> glucose + oxygen
                 (IN)                              (OUT)

RESPIRATION      glucose + oxygen -----------> carbon dioxide + water + ATP
                 (IN)                          (OUT)
```

**Same substances, opposite sides**:
```
                    photosynthesis      respiration
carbon dioxide      reactant  (in)      product  (out)
oxygen              product   (out)     reactant (in)
glucose             product   (out)     reactant (in)
```

**Where and when**:
```
photosynthesis   chloroplasts, needs light      plants only
respiration      mitochondria, all the time     plants AND animals
```

**Guidelines for the question text:**
- Ask whether a substance is a reactant or a product, and of which reaction.
- Plants respire too — the common misconception worth heading off.
