When explaining this question, use ONE of these visual structures:

**Three independent lines of evidence, all pointing the same way**:
```
FOSSIL RECORD      older rock layers    ->  simpler / different species
                   newer rock layers    ->  species closer to today's

BODY STRUCTURE     human arm  bat wing  whale flipper
                   same bones, different jobs  -> a shared ancestor

DNA                the more DNA two species share,
                   the more recently they shared an ancestor
```

**Evidence test** — does it show INHERITED change over generations?
```
fossils in dated layers        yes  (change over time)
shared bone structures         yes  (shared ancestry)
DNA similarity                 yes  (shared ancestry)
the colour of a painted wall   no   (nothing inherited)
the price of fuel              no   (not about living things)
```

**Guidelines for the question text:**
- Ask which option IS evidence, with distractors that are simply unrelated facts.
- Evolution is change in a POPULATION across generations, never in one individual.
