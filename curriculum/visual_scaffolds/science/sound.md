When writing or explaining this question, use ONE of these visual structures:

**Vibration-to-sound chain**:
```
OBJECT MOVES BACK AND FORTH  →  AIR AROUND IT SHAKES  →  YOU HEAR SOUND
      (this is "vibrating")         (sound travels)         (your ear)
```

**Vibrating vs. still** — side-by-side comparison:
```
VIBRATING (makes a sound)       NOT VIBRATING (silent)
  a plucked guitar string         a guitar string not touched
  a struck drum skin               a rock sitting still
  a ringing bell                   a book on a shelf
```

**Guidelines for the question text:**
- Multiple-choice only (verifier uses curated fact tables, never LLM assertion).
- Give ONE object; ask whether it makes a sound BY VIBRATING, not just "does it make a sound"
  — a rock struck against something can make a sound, but it isn't the vibrating object in the
  same sense a plucked string or struck drum is; keep examples to objects that are clearly
  either vibrating-to-make-sound or sitting still and silent, not edge cases.
- "Vibrating" means moving back and forth very quickly — you can sometimes feel it (touch a
  speaker, or your throat while humming).
