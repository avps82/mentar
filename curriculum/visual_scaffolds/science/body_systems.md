When writing or explaining this question, use ONE of these visual structures:

**Digestive vs. circulatory** — side-by-side comparison:
```
DIGESTIVE SYSTEM (breaks down food)   CIRCULATORY SYSTEM (moves blood)
  the stomach, the intestines           the heart, the veins
  the oesophagus, the liver             the arteries, red blood cells
  (food travels through this path)      (blood travels through this path)
```

**Simple path diagram**:
```
DIGESTIVE:    mouth → oesophagus → stomach → intestines
CIRCULATORY:  heart → arteries → (body) → veins → heart
```

**Guidelines for the question text:**
- Give ONE organ or body part and ask which system it belongs to.
- Keep to the two systems above — don't mix in the respiratory system (lungs) or nervous
  system unless the node explicitly covers those.
