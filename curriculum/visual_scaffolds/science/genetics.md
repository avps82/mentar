**Code vs. product** — the trap in this question type:
```
THE CODE (genetic information)      WHAT THE CODE BUILDS (proteins)
DNA                                 haemoglobin  (carries oxygen)
a gene                              insulin      (controls blood sugar)
a chromosome                        an enzyme    (speeds up a reaction)
```

**Guidelines for the question text:**
- Ask which option carries genetic information, or which is a protein instead.
- Keep the analogy consistent: DNA is the recipe, protein is the meal.
