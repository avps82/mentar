When explaining this question, use ONE of these visual structures:

**The negative-feedback loop**:
```
        set point
            |
   change --+--> RECEPTOR detects it
                     |
                 COORDINATOR
                     |
                 EFFECTOR acts
                     |
            <-- the change is REVERSED, back toward the set point
```

**Two worked examples**:
```
too HOT   -> sweat, blood vessels widen   -> temperature falls back
too COLD  -> shiver, blood vessels narrow -> temperature rises back
glucose UP after a meal -> insulin released -> glucose falls back
```

**Is it homeostasis?**
```
Does the response UNDO the change, back to a set point?   -> yes, homeostasis
A one-way change with no set point (growing, ageing)?     -> not homeostasis
```

**Guidelines for the question text:**
- Give a body response and ask whether it is negative feedback.
- "Negative" means the change is reversed, not that anything is bad.
