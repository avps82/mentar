When writing or explaining this question, use this visual structure:

```key
PUSH → (away from you): kick a ball, press a doorbell
PULL ← (toward you): open a fridge, drag a wagon
TWIST ↻: turn a tap
```

**Guidelines for the question text:**
- The arrow direction IS the definition — draw it with every example.
