When explaining this question, use ONE of these visual structures:

**Three reaction types by what goes in and what comes out**:
```
COMBUSTION       fuel + oxygen        ->  oxides + energy released
                 methane + O2         ->  CO2 + H2O + heat

NEUTRALISATION   acid + base          ->  a salt + water
                 HCl + NaOH           ->  NaCl + H2O

PRECIPITATION    two solutions mix    ->  one product will NOT dissolve
                 (a solid appears in a clear liquid)
```

**What you would SEE**:
```
combustion      a flame, heat, light
neutralisation  fizzing stops, pH moves toward 7, warmth
precipitation   the liquid turns cloudy; a solid settles out
```

**Guidelines for the question text:**
- Describe what happens and ask for the reaction type, or give the type and ask for the example.
- Mass is conserved in all three: nothing is created or destroyed, only rearranged.
