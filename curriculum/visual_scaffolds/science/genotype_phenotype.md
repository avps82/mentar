When explaining this question, use ONE of these visual structures:

**The letters you carry vs. the thing you can see**:
```
GENOTYPE   the alleles themselves      BB    Bb    bb
PHENOTYPE  what you can observe        brown eyes  brown eyes  blue eyes
                                        ^-- Bb LOOKS like BB: the dominant allele masks b
```

**Dominant and recessive**:
```
BB   homozygous dominant     shows the dominant characteristic
Bb   heterozygous            shows the dominant characteristic (b is masked)
bb   homozygous recessive    the ONLY way the recessive one shows
```

**Punnett square**:
```
        B     b
    B   BB    Bb
    b   Bb    bb        3 of 4 show the dominant phenotype, 1 of 4 the recessive
```

**Guidelines for the question text:**
- Ask which option is a genotype and which is a phenotype; letters vs. description is the tell.
- A recessive characteristic needs BOTH alleles recessive — worth saying every time.
