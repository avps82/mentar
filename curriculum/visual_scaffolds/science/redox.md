When explaining this question, use ONE of these visual structures:

**OIL RIG**:
```key
Oxidation Is Loss    of electrons     Mg -> Mg(2+) + 2e-     oxidation number RISES
Reduction Is Gain    of electrons     Cu(2+) + 2e- -> Cu     oxidation number FALLS
```

**Both always happen together**:
```
Mg  +  Cu(2+)   ->   Mg(2+)  +  Cu
 |        |            |          |
 loses    gains        oxidised   reduced
 2e-      2e-
```

**Everyday examples**:
```
iron rusting            oxidised (loses electrons to oxygen)
metal ore -> metal      reduced  (gains electrons in the furnace)
```

**Guidelines for the question text:**
- Give a half-change and ask which it is; follow the electrons, not the oxygen.
- Name the partner: if something is oxidised, something else is reduced.
