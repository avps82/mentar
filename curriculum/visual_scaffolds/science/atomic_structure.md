When explaining this question, use ONE of these visual structures:

**Where each particle sits**:
```key
            ELECTRONS  (negative, tiny, orbit in shells)
                 ·           ·
            ·   ┌───────────┐   ·
                │  NUCLEUS  │        <- protons + neutrons, packed together
            ·   │  p+  n0   │   ·
                └───────────┘
                 ·           ·

  IN the nucleus:      protons (+)  ·  neutrons (no charge)
  OUTSIDE it:          electrons (-)
```

**Charge table**:
```
Particle    Charge     Where it is        Mass
proton      +1         in the nucleus     ~1
neutron      0         in the nucleus     ~1
electron    -1         shells outside     ~1/1836  (almost nothing)
```

**Bigger-than-an-atom check** — a common trap in this question type:
```
electron / proton / neutron   = PARTS of an atom  (subatomic)
atom                          = one whole atom
molecule / compound           = MADE OF atoms     (bigger, not subatomic)
```

**Guidelines for the question text:**
- Ask where a named particle sits, or which option is not a subatomic particle at all.
- Never ask a child to recall exact masses; the comparison (electrons are far lighter) is the point.
