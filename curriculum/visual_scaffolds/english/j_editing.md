When writing or explaining this question, use this visual structure:

```key
1. REDRAFT: move whole paragraphs
2. EDIT: sharpen sentences, cut repeats
3. PROOFREAD: spelling, capitals, stops — last
```

**Guidelines for the question text:**
- Big changes first, tiny fixes last — never the reverse.
