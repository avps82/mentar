When writing or explaining this question, use this visual structure:

```key
sonnet: 14 lines ────────┐ volta (the turn)
haiku:  5 / 7 / 5 syllables — one image
free verse: no set rhyme or meter; the line-break is the instrument
```

**Guidelines for the question text:**
- Count something visible: lines for the sonnet, syllables for the haiku.
