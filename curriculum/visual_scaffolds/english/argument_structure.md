When explaining this question, use ONE of these visual structures:

**The three moves of an argument**:
```key
CLAIM      what you are arguing        "Peak-hour transport should be free."
EVIDENCE   a fact or example for it    "Ridership rose 14% when fares were cut."
REBUTTAL   answering the other side    "Critics say it costs too much, but
                                        road repairs cost more."
```

**Which move is this sentence making?**
```
Does it state a position?          -> CLAIM
Does it give a fact or example?    -> EVIDENCE
Does it name and answer an         -> REBUTTAL
  opposing view ("some argue...")?
```

**Guidelines for the question text:**
- Give one sentence from an argument and ask which move it makes.
- A rebuttal must NAME the opposing view before answering it.
