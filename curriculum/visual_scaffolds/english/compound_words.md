When explaining this question, use ONE of these visual structures:

**Two real words, joined into one real word**:
```
sun + flower   =  sunflower     a flower that follows the sun
tooth + brush  =  toothbrush    a brush for your teeth
basket + ball  =  basketball    a ball game with baskets
butter + fly   =  butterfly     (a real word, even though it is not buttery)
```

**The trap** -- two real words joined is NOT automatically a word:
```
moon + brush  ->  "moonbrush"   nobody uses this: not a word
chair + water ->  "chairwater"  not a word either
```

**Guidelines for the question text:**
- Ask which option is a REAL compound word; the distractors should be plausible-but-invented.
- Say what the two parts contribute, where the meaning is transparent.
