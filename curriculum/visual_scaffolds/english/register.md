When explaining this question, use ONE of these visual structures:

**Register — who is being spoken to**:
```
                FORMAL                        INFORMAL
audience        examiner, employer, stranger   friend, family
contractions    avoided ("do not")             used ("don't")
words           "suggests", "examines"         "looks like", "so"
example         "The evidence suggests a       "Looks like it got a
                 modest improvement."           bit better."
```

**Same content, two registers** — a useful pairing to show side by side:
```
formal:    "The results were inconsistent with the hypothesis."
informal:  "Yeah, that didn't go how we thought."
```

**Guidelines for the question text:**
- Give an audience and ask which wording fits, or give a line and ask who it is for.
- Register is about AUDIENCE; tone is about attitude. Keep them apart.
