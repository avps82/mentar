When explaining this question, use ONE of these visual structures:

**What is the phrase doing?**
```
ADVERBIAL PHRASE (tells HOW, WHEN or WHERE)    NOUN PHRASE (names a thing)
in the morning        -- when                  the big red car
very quickly          -- how                   my best friend
under the table       -- where                 a beautiful sunset
with great care       -- how                   the old oak tree
```

**Question test**:
```
Ask "how / when / where?"  -> it answers   -> ADVERBIAL phrase
Ask "what thing?"          -> it answers   -> NOUN phrase
```

**Guidelines for the question text:**
- Give a phrase, not a full sentence, and ask which kind it is.
- An adverbial phrase describes the ACTION; a noun phrase names a THING.
