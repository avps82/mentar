When explaining this question, use ONE of these visual structures:

**A suffix goes on the END and changes the meaning**:
```
SUFFIX   MEANS               EXAMPLE           NOW MEANS
-ful     full of             joy + ful         full of joy
-less    without             care + less       without care
-ness    the state of being  kind + ness       the state of being kind
```

**Same root, opposite ends**:
```
care + ful   ->  careful   (full of care)
care + less  ->  careless  (without care)
```

**Guidelines for the question text:**
- Pair -ful with -less on the same root; the contrast teaches both at once.
- -ness turns a describing word into a thing you can talk about.
