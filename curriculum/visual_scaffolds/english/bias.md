When explaining this question, use ONE of these visual structures:

**Bias check — swap the loaded words out and see what is left**:
```
"A MOB of protesters SWARMED the square."     -> loaded (mob, swarmed)
"A CROWD of protesters GATHERED in the square." -> balanced, same event
```

**Guidelines for the question text:**
- Give the same event worded two ways; ask which is slanted and which words do it.
- Bias is in the WORD CHOICE, not in the facts themselves.
