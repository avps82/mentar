When explaining this question, use ONE of these visual structures:

**How many things are being compared?**
```
PLAIN        TWO THINGS (-er)      THREE OR MORE (-est)
big          bigger                biggest
fast         faster                fastest
tall         taller                tallest
```

**Read it in a sentence**:
```
"Sam is TALLER than Jo."            two people  -> comparative
"Sam is the TALLEST in the class."  the whole class -> superlative
```

**Guidelines for the question text:**
- The count decides the ending: two takes -er, three or more takes -est.
- "the" in front is a strong clue for the superlative.
