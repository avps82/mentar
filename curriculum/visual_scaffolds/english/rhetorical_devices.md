When explaining this question, use ONE of these visual structures:

**Rhetorical devices — what each one does to the reader**:
```
rhetorical question   asks without wanting an answer   "Who wouldn't want this?"
direct address        speaks to the reader as "you"    "Your street, your choice."
repetition            drums the idea in                "We tried, we failed, we tried."
```

**Guidelines for the question text:**
- Give one short line and ask which device it uses.
- Always name the EFFECT on the reader, not just the label.
