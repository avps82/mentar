When writing or explaining this question, use the matching structure for the word type:

**Plurals — rule table**:
```
Ending          Rule             Example
most words    → add -s          cat → cats
-s, -sh, -ch  → add -es         dish → dishes
-y (after C)  → change to -ies  baby → babies
-y (after V)  → add -s          monkey → monkeys
-f / -fe      → change to -ves  leaf → leaves
irregular     → change whole    mouse → mice
```

**Compound words — two words joined**:
```
sun  +  flower  =  sunflower
foot +  ball    =  football
rain +  coat    =  raincoat
```
Ask: "Can you spot the two smaller words hiding inside?"

**Rhyming words — same ending sound (not necessarily spelling)**:
```
cat / bat / hat / mat / sat    (−at family)
night / write / kite / light   (−ight/−ite family, different spellings!)
```
Show both same-spelling and different-spelling rhymes to separate sound from spelling.

**Guidelines for the question text:**
- Plurals: present the base word and the rule; ask the child to apply it.
- Compound words: show the two parts joined; ask "what two words make this?"
- Rhyming: give a word + 4 options, one rhyme and three distractors (same initial sound ≠ rhyme).
- Year 2: common regular plurals and simple rhyme families. Year 3+: irregular plurals and compound words.
