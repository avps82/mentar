When explaining this question, use ONE of these visual structures:

**Count the clauses**:
```
SIMPLE    [ The train left early. ]
          one main clause, stands alone

COMPOUND  [ The train left early ] + but + [ we caught it. ]
          TWO main clauses -- either half could stand alone

COMPLEX   ( Although the train left early, ) [ we caught it. ]
          one main clause + a subordinate clause that CANNOT stand alone
```

**Joining-word clue**:
```
and, but, so, or        -> usually COMPOUND (two equals joined)
although, because,      -> usually COMPLEX  (one part depends on the other)
  when, if, while
no joining word         -> SIMPLE
```

**Stand-alone test** — cover half the sentence and read the rest aloud:
```
"we caught it"                  makes sense alone -> main clause
"although the train left early" does NOT          -> subordinate clause
```

**Guidelines for the question text:**
- Give one sentence and ask for its type; the joining word is the clue, not the length.
- A long sentence can be simple, and a short one can be complex.
