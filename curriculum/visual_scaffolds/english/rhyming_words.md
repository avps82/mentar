When explaining this question, use ONE of these visual structures:

**Rhyme is about SOUND, not spelling**:
```
pig   ->  big   dig   wig        (-ig)
bell  ->  shell well  tell       (-ell)
king  ->  sing  ring  wing       (-ing)
boat  ->  coat  goat  float      (-oat)
```

**Same sound, different spelling** -- this is why listening beats looking:
```
tree  and  key      rhyme   (ee / ey)
blue  and  through  rhyme   (ue / ough)
```

**Guidelines for the question text:**
- Say both words aloud; the ENDING sound is the test, not the last letters.
- Include one same-spelling-different-sound trap only when the child is ready for it.
