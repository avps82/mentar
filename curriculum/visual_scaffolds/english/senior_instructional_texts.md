When writing or explaining this question, use this visual structure:

```key
GOAL → WHAT YOU NEED → STEPS (numbered, in doing order)
1. Press…   2. Hold…   3. Release…   ← command verbs first
test: could a stranger DO it from the words alone?
```

**Guidelines for the question text:**
- Contrast one instruction line with one story line — the verb position differs.
