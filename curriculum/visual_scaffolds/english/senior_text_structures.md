When writing or explaining this question, use this visual structure:

```key
cause-effect:      A ──because──► B ──so──► C
compare-contrast:  A │ B   (however, whereas)
chronological:     first → then → finally
```

**Guidelines for the question text:**
- The signal words are the fingerprints — list them with each shape.
