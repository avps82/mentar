When explaining this question, use ONE of these visual structures:

**Allusion versus plain description**:
```
ALLUSION                              PLAIN DESCRIPTION
"He met his Waterloo."                "He lost badly."
"She opened a Pandora's box."         "She started a lot of trouble."
"The plan was his Achilles heel."     "The plan had one weakness."
```

**What the reference brings with it**:
```
"Waterloo"      -> Napoleon's final defeat   -> a total, final loss
"Pandora's box" -> the Greek myth            -> troubles that cannot be put back
"Achilles heel" -> the one vulnerable spot   -> a single fatal weakness
```

**Test**: does understanding the line depend on knowing something else?
```
yes -> ALLUSION      no -> plain description
```

**Guidelines for the question text:**
- Pair each allusion with the plain wording of the same idea.
- Say what the reference ADDS; an allusion nobody recognises does no work.
