When explaining this question, use ONE of these visual structures:

**Same meaning, or opposite meaning?**
```
                 SYNONYMS (same)              ANTONYMS (opposite)
  happy    ->    glad, cheerful, pleased      sad, miserable
  big      ->    large, huge, giant           small, tiny
  cold     ->    chilly, icy, freezing        hot, warm
```

**Word line** -- synonyms cluster, antonyms sit at the other end:
```
   freezing   cold   cool  |  warm   hot   boiling
   \________ same side ___/     \____ opposite ____/
```

**Swap test**:
```
Put the word into the sentence. Does the meaning stay the same?  -> synonym
Does it flip to the opposite?                                    -> antonym
```

**Guidelines for the question text:**
- Ask for SAME or OPPOSITE explicitly; a bare "which word goes with" is ambiguous.
- Synonyms are rarely identical -- say what shade of meaning differs when it matters.
