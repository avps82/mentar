When explaining this question, use ONE of these visual structures:

**Evaluative vs. neutral — the same fact, two jobs**:
```
EVALUATIVE (it judges)          NEUTRAL (it reports)
a disgraceful decision          a unanimous decision
an outstanding performance      a two-hour performance
a reckless proposal             a written proposal
```

**Guidelines for the question text:**
- Pair the same fact stated both ways; ask which one judges.
- Evaluative wording belongs in an argument, neutral wording in a report.
