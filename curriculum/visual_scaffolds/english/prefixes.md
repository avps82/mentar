When explaining this question, use ONE of these visual structures:

**A prefix goes on the FRONT and changes the meaning**:
```
PREFIX   MEANS            EXAMPLE          NOW MEANS
un-      not / opposite   un + happy       not happy
re-      again            re + play        play again
dis-     not / opposite   dis + agree      not agree
```

**Split it to check**:
```
unlock   ->  un + lock   ->  the opposite of lock
rebuild  ->  re + build  ->  build it again
```

**Guidelines for the question text:**
- Ask which word carries a given prefix, or what the prefix does to the meaning.
- Split the word visibly: the prefix is only a prefix if a real word is left behind.
