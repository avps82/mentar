When writing or explaining this question, use ONE of these visual structures:

**Three-box label** — colour-code by word class:
```
The  quick  fox   jumps  gracefully.
 │     │     │      │        │
art   adj.  noun   verb    adverb
       ↑     ↑      ↑
  describing naming  doing
    word     word    word
```

**Question test** — each word class answers a different question:
```
Noun    → "What/who is it?"     e.g. fox, school, happiness
Verb    → "What is it doing?"   e.g. jumps, runs, thinks
Adjective → "What is it like?"  e.g. quick, red, tall
Adverb  → "How/when/where?"     e.g. gracefully, yesterday, here
```

**Sentence-slot frame** — fill in the right word class:
```
The [describing word] [naming word] [doing word] quickly.
The  big               cat           sat          quickly.
```

**Guidelines for the question text:**
- Year 2: nouns and verbs only — use "naming word" and "doing word" language.
- Year 3–4: add adjectives ("describing words"); introduce adverbs.
- Year 5+: use the technical labels (noun, verb, adjective, adverb).
- One sentence per question; ask about ONE underlined word only.
