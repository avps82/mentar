When writing or explaining this question, use this visual structure:

**Category map** — show what groups the words belong to:
```
apple   banana   carrot   grape
  ↓        ↓        ↓       ↓
 fruit    fruit  vegetable  fruit

→ "carrot" is the odd one out (not a fruit)
```

**Two-step reasoning layout**:
```
Step 1 — Name the category for most words: "apple, banana, grape → all fruits"
Step 2 — Identify what breaks the pattern:  "carrot → vegetable, not a fruit"
Step 3 — State the odd one out with reason: "carrot because it is a vegetable"
```

**Multiple possible categories (advanced)**:
```
red   blue   run   green

Category A (colours): red, blue, green → odd one out = run
Category B (3 letters): red, run, blue → odd one out = green
→ Expect the child to justify THEIR choice with a clear reason.
```

**Guidelines for the question text:**
- Always ask for a reason, not just the word ("which word does not belong and why?").
- Year 2–3: concrete, familiar categories (animals, colours, food, shapes).
- Year 4–6: word class categories (3 nouns + 1 verb), meaning categories.
- When there is more than one defensible answer, accept any with a valid reason.
