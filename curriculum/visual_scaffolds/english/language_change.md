When explaining this question, use ONE of these visual structures:

**Two ways English gains a word**:
```
BORROWED from another language          COINED for something new
kindergarten  <- German                 podcast     (iPod + broadcast)
safari        <- Swahili                smartphone  (smart + phone)
typhoon       <- Chinese / Arabic       software    (soft + ware)
bungalow      <- Hindi                  livestream  (live + stream)
```

**Test to tell them apart**:
```
Could the word exist before the thing did?
  no, the thing is new technology  -> COINED
  yes, the word travelled from another language -> BORROWED
```

**Guidelines for the question text:**
- Ask where a word came from; keep the pairs concrete.
- Language change is neutral: newer words are not worse words.
