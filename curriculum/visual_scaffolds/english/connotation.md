When explaining this question, use ONE of these visual structures:

**Same basic meaning, different feeling**:
```
POSITIVE          NEUTRAL          NEGATIVE
slender           thin             skinny
confident         sure             arrogant
curious           interested       nosy
frugal            careful          stingy
```

**Which would you rather be called?**
```
"She is slender."   sounds like a compliment
"She is skinny."    sounds like a criticism
                    -- same body, different word choice
```

**Guidelines for the question text:**
- Give two words with the same denotation and ask which one flatters.
- Connotation is about the FEELING attached, not about the dictionary definition.
