When explaining this question, use ONE of these visual structures:

**The apostrophe marks the missing letters**:
```
TWO WORDS      ->  CONTRACTION     WHAT THE ' REPLACES
do not         ->  don't           the o in not
cannot         ->  can't           the n and o
it is          ->  it's            the i in is
I am           ->  I'm             the a in am
they are       ->  they're         the a in are
will not       ->  won't           (irregular -- learn this one)
```

**Expand it to check**:
```
"it's raining"  ->  "it is raining"   makes sense -> correct
"it's tail"     ->  "it is tail"      does NOT    -> should be "its"
```

**Guidelines for the question text:**
- Give the full pair and ask for the short form, or the reverse.
- The apostrophe stands for the letters taken out -- never for a plural.
